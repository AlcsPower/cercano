# TC-F1-009: Smoke Test Automatizado E2E de Fase 1

- **Tarea asociada:** F1-09
- **Rol ejecutor:** Agente-QA
- **Automatizable:** Sí (`tests/e2e/smoke.ps1` y `tests/e2e/smoke.sh`)
- **Frecuencia:** CI nocturno y bajo demanda en PR / merge

## Objetivo
Validar el flujo completo de inicio, aprovisionamiento, comunicación LAN y ciclo de vida de clientes en Cercano:
1. Salud de servicios y puertos (`cercano-api`, `hbbs`, `hbbr`).
2. Obtención de clave pública Ed25519 del servidor (`GET /api/server/public-key`).
3. Bootstrap y autenticación de sesión de administrador (`POST /api/auth/bootstrap`, `POST /api/auth/login`).
4. Registro de dos clientes (`cercano-client-a` y `cercano-client-b`) con metadatos reales/sintéticos vía `POST /api/devices/heartbeat`.
5. Inventario dinámico y estado `online` (`GET /api/devices`).
6. Conectividad y accesibilidad simultánea de rendezvous (21116 TCP/UDP) y relay (21117 TCP).
7. Transición dinámica a `offline` de dispositivos tras expiración de tiempo de gracia (`device_grace_period_secs`).

## Precondiciones
- Infraestructura Docker levantada (`deploy/docker-compose.yml` o laboratorio LAN).
- Puertos 21114, 21115, 21116, 21117 disponibles.
- Clave pública Ed25519 generada en el servidor.

## Pasos de ejecución
1. Ejecutar `powershell -File tests/e2e/smoke.ps1` o `bash tests/e2e/smoke.sh`.
2. Verificar respuesta HTTP 200 en `/healthz` y conectividad TCP a 21114, 21115, 21116, 21117 y probe UDP a 21116.
3. Consultar `/api/server/public-key` y validar par Ed25519 de 32 bytes (44 caracteres Base64).
4. Ejecutar bootstrap de administrador e iniciar sesión para obtener Bearer token.
5. Emitir latidos con `cercano-client-a` y `cercano-client-b`.
6. Consultar `/api/devices` con token Bearer y verificar presencia y metadatos con estado `online`.
7. Verificar conectividad de relay y rendezvous.
8. Registrar dispositivo de prueba temporal, esperar ventana de gracia y verificar transición a `offline`.

## Resultado esperado
- Todas las subpruebas (15/15) en estado `PASS`.
- Tiempo total de ejecución < 15 segundos.
- Código de salida 0.
- Informe estructurado exportado a `tests/e2e/results.json`.
