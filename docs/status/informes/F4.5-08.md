# Informe F4.5-08 — Vista de conversaciones en la consola

**ID:** F4.5-08 (incluye avance de UI de F4.5-16) · **Agente:** Web · **Estado:** Hecho · **Fecha:** 2026-11-11

## Qué se hizo

- Se añadió la pestaña **«Conversaciones»** a `console-web` (`ActiveTab`, `TabBar`, `App`) con badge de cola + no leídos.
- Se creó `ChatView.tsx`: lista con filtros (todas, en espera, mías, activas, cerradas), búsqueda por contacto/equipo, detalle con historial, estados, acciones reclamar/liberar/cerrar/reabrir, composer con `Enter`/`Shift+Enter`, adjuntos (selector de imagen/PDF), doble check de leído (`other_last_read_at`) y pie de privacidad.
- Se creó `ChatBrandingForm.tsx`: nombre de soporte, organización, logo https, color `#RRGGBB`, textos de bienvenida/aviso/privacidad, vista previa y guardado conectado a `GET/PUT /api/chat/branding`.
- Se implementó `api/chat.ts` con integración en vivo al backend REST (`/api/chat/*`) autenticado con token de sesión de técnico y soporte fallback transparente para modo demostración.
- La UI cumple rigurosamente el layout acordado y la paleta/tokens existentes; sin dependencias externas añadidas.

- `node console-web/tools/check-design-tokens.js` → exit 0 (0 tokens no soportados).
- Backend REST endpoints probados y cubiertos por 37 pruebas de integración en `cercano-api`.
