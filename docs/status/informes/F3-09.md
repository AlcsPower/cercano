# Informe de Tarea F3-09 — Revocación y Caducidad

```
ID: F3-09      Agente: Agente-ControlPlane + Servidor      Estado: Hecho
Qué se hizo:
Se implementó el subsistema de revocación y caducidad para instaladores y perfiles en `control-plane/cercano-api`:
- Publicación de lista activa de revocaciones en `GET /api/builds/revocations` y `GET /api/revocations` con cabeceras `Cache-Control: public, max-age=60`, `ETag` determinista y soporte `If-None-Match` (304 Not Modified).
- Revocación individual `POST /api/builds/{id}/revoke` y por rol completo `POST /api/builds/revoke-role/{role}` con control de acceso RBAC (`builder:revoke` o `admin`) y auditoría estructurada `build.revoked`.
- Verificador en memoria `RevocationChecker` con TTL configurable (30-60s), invalidación instantánea local y degradación configurable (`fail_closed` / `fail_safe`).
- Rechazo en `heartbeat_handler` (`devices.rs`) ante instaladores revocados o caducados (`expires_at < now`) con HTTP 403 Forbidden (`installer_revoked`, `installer_expired`), persistencia de `installer_id`/`profile_id` y auditoría estructurada `build.registration_rejected`.

Evidencia:
- `wsl -e bash -lc "cargo test -p cercano-api --test revocation_test"`: 7 pruebas específicas aprobadas (TC-F3-090 a TC-F3-096).
- `wsl -e bash -lc "cargo test -p cercano-api"`: 122 pruebas pasadas (78 unitarias en lib.rs, 1 main, 10 alarms, 1 admin mutations, 9 audit routes, 11 build routes, 7 revocation, 5 trace correlation).
- `wsl -e bash -lc "cargo clippy -p cercano-api -- -D warnings"`: En verde, 0 advertencias.
- `wsl -e bash -lc "cargo clippy -p cercano-api --tests -- -D warnings"`: En verde, 0 advertencias.
- `wsl -e bash -lc "cargo fmt -p cercano-api -- --check"`: En verde, formato canónico.
```
