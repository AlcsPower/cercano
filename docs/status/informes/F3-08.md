# Informe de tarea: F3-08 — Auditoría `build.*`

ID: F3-08      Agente: ControlPlane      Estado: Hecho

## Qué se hizo
- Se implementó la emisión completa, secuenciada y encadenada criptográficamente de todos los eventos de auditoría `build.*` (`build.requested`, `build.started`, `build.completed`, `build.failed`, `build.downloaded`, `build.revoked`).
- Se integró `Arc<audit_core::AuditStore>` en el worker de `BuildQueue` (`process_build_task`) y en los manejadores de rutas de compilación (`enqueue_build_handler`, `download_build_handler`).
- Se implementó el endpoint `POST /api/builds/{id}/revoke` con control RBAC, verificación de estados, emisión de `build.revoked` y bloqueo de descarga para instaladores revocados (retorno 410 Gone).
- Se añadió la función `sanitize_profile` para serializar de forma segura el perfil sin exponer secretos, y se registró `"build_job"` en el esquema taxonómico `docs/specs/audit-events.schema.json`.
- Se crearon pruebas de integración automatizadas en `tests/build_routes_test.rs` cubriendo el ciclo de vida completo de auditoría, manejo de fallos y ausencia de fuga de credenciales o secretos.
