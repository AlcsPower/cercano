# Informe de Tarea F4.5-13: Perfil policy.chat y aplicación en servidor y cliente

**ID de tarea:** F4.5-13  
**Agente:** Agente-ControlPlane / Agente-Cliente  
**Fecha:** 2026-11-16  
**Estado:** Hecho  
**Rama:** `docs/F0-01-gobernanza`  

---

## 1. Qué se hizo

1. **Extensión del esquema de perfil firmado (`cercano-profile`):**
   - Se incorporó la subsección opcional `policy.chat` en `docs/specs/cercano-profile.schema.json` y se documentó en `docs/specs/cercano-profile.md`.
   - Propiedades:
     - `enabled`: boolean opcional. Por defecto es `true` para rol `soporte`, `false` para rol `tecnico`.
     - `allow_attachments`: boolean (por defecto `true`).
     - `allow_remote_escalation`: boolean (por defecto `true`).

2. **Control-Plane (`control-plane/cercano-api/`):**
   - Se actualizó `profile.rs` añadiendo la estructura `ChatPolicyConfig` con defaults seguros dentro de `PolicyConfig`.
   - Se agregó control estricto de roles en `chat/conversations.rs`: las peticiones de creación de conversación realizadas por dispositivos con rol `tecnico` son denegadas inmediatamente (`403 Forbidden`).
   - Se integraron verificaciones de cabeceras de política en los endpoints de chat:
     - `POST /api/chat/conversations/:id/attachments`: deniega con `403 Forbidden` si la política deshabilita adjuntos (`x-cercano-policy-allow-attachments: false`).
     - `POST /api/chat/conversations/:id/escalate`: deniega con `403 Forbidden` si la política deshabilita escalado a sesión remota (`x-cercano-policy-allow-remote-escalation: false`).

3. **Cliente (`vendor/client/`):**
   - Se actualizó `src/cercano_profile.rs` deserializando `policy.chat` mediante `ChatPolicyDto`.
   - Se incluyeron los campos `chat_enabled`, `chat_allow_attachments`, `chat_allow_remote_escalation` en `VerifiedProfileInfo`.
   - Se expusieron las funciones públicas de verificación `is_chat_enabled()`, `is_chat_allow_attachments()` y `is_chat_allow_remote_escalation()`.
   - Se generó el parche `patches/011-client-policy-chat.patch` y se registró en `patches/INDEX.md`.
