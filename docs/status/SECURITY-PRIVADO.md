# Hallazgos de seguridad internos

Registro de hallazgos detectados durante el desarrollo, antes de publicarlos o corregirlos. **No incluyas secretos ni datos reales.** Si el repositorio pasa a ser público, mueve este archivo a un canal privado.

Formato por hallazgo: ID (`S-NNN`), fecha, componente, severidad (crítica/alta/media/baja), descripción, impacto, propuesta de mitigación, estado.
